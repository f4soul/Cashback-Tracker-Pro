# Cashback Tracker Pro

Cashback Tracker Pro — это удобное веб-приложение (PWA) для отслеживания и анализа категорий кэшбека по вашим банковским картам. Приложение помогает консолидировать все категории кэшбека в одном месте, визуализировать данные и эффективно планировать ваши траты для получения максимальной выгоды.

## 🌟 Основные возможности

*   **Учет кэшбека:** Добавляйте и редактируйте информацию о кэшбеке по разным категориям для каждого вашего банка.
*   **Архивация:** Сохраняйте данные за прошлые месяцы и просматривайте историю в удобном архиве.
*   **Кастомные банки и категории:** Создавайте свои собственные банки (с загрузкой логотипов) и уникальные категории.
*   **Визуализация:** Удобная и адаптивная таблица для просмотра актуальных данных.
*   **Экспорт:** Возможность выгрузки данных в форматах **Excel**, **PDF** и **PNG** (изображение).
*   **Облачная синхронизация:** Автоматическое сохранение данных в облаке при входе через Google-аккаунт.
*   **Персонализация:** Настройка внешнего вида (темная/светлая/системная тема, форма логотипов, акцентные цвета, скругления).
*   **PWA:** Поддержка установки на мобильные устройства, работа с Safe Area и офлайн-возможности (через кеширование).

## 🛠 Технологии

Приложение построено на современном и быстром стеке:

*   **Frontend:** React 19, TypeScript, Vite, Tailwind CSS 4.
*   **Backend/Database:** Firebase (Firestore для данных, Firebase Auth для авторизации, Storage для кастомных логотипов).
*   **Анимации:** Motion (бывший Framer Motion).
*   **UI/Утилиты:** Lucide React (иконки), dnd-kit (Drag-and-Drop), sonner (тосты).
*   **Экспорт:** html-to-image, jspdf, xlsx.

## 🚀 Начало работы

### Требования
*   Node.js (версия 18+)
*   npm, yarn или bun
*   Свой проект в Firebase (для базы данных и авторизации)

### Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/yourusername/cashback-tracker-pro.git
   cd cashback-tracker-pro
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Настройте переменные окружения:
   * Скопируйте файл конфигурации: `cp .env.example .env`
   * Создайте новый проект в [Firebase Console](https://console.firebase.google.com/).
   * Включите **Firestore Database**, **Storage** и **Authentication** (Google Sign-In).
   * Скопируйте ключи вашего Firebase-проекта в файл `.env`.

4. Разверните правила безопасности Firebase (Firestore):
   * В корне проекта находится файл `firestore.rules`.
   * Вы можете скопировать его содержимое в раздел Rules вашего Firestore в Firebase Console, либо развернуть через Firebase CLI.

5. Запустите проект в режиме разработки:
   ```bash
   npm run dev
   ```

6. Откройте `http://localhost:3000` в вашем браузере.

## 📁 Структура проекта

*   `src/components/` — переиспользуемые UI-компоненты (формы, таблицы, модалки).
*   `src/views/` — основные экраны приложения (текущий месяц, архив, настройки).
*   `src/hooks/` — изолированная stateful-логика (авторизация, синхронизация с облаком, CRUD, темы).
*   `src/utils/` — вспомогательные функции (экспорт, форматирование дат, обработка изображений).
*   `src/firebase.ts` — конфигурация и инициализация Firebase.

Более подробная информация об архитектуре находится в файле [DOCUMENTATION.md](./DOCUMENTATION.md).
