# Cashback Tracker Pro

Cashback Tracker Pro — это удобное веб-приложение для отслеживания и анализа категорий кэшбека по вашим банковским картам. Приложение помогает визуализировать, в каких категориях вы получаете больше всего кэшбека, и эффективно управлять настройками ваших банков.

## Основные возможности

*   **Учет кэшбека:** Добавляйте и редактируйте информацию о кэшбеке по разным категориям для каждого банка.
*   **Архивация:** Сохраняйте данные за прошлые месяцы и просматривайте историю.
*   **Настройка:** Создавайте свои собственные банки и категории, если их нет в стандартном списке.
*   **Визуализация:** Удобная таблица для просмотра актуальных данных.
*   **Экспорт:** Возможность выгрузки данных в форматах **Excel**, **PDF** и **PNG** (изображение).
*   **Облачная синхронизация:** Автоматическое сохранение данных в облаке при входе через Google-аккаунт.
*   **Персонализация:** Настройка внешнего вида (темная/светлая тема, форма логотипов, акцентные цвета).

## Технологии

Приложение построено на современном стеке:
*   **Frontend:** React (Vite), TypeScript, Tailwind CSS.
*   **Backend/Database:** Firebase (Firestore для данных, Firebase Auth для авторизации).
*   **Анимации:** Motion (framer-motion).
*   **Экспорт:** html-to-image, jspdf, xlsx.

## Начало работы

### Требования
*   Node.js (версия 18+)
*   npm или yarn

### Установка и запуск
1. Клонируйте репозиторий.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите проект в режиме разработки:
   ```bash
   npm run dev
   ```
4. Откройте `http://localhost:3000` в вашем браузере.

## Структура проекта
*   `src/components/` — переиспользуемые UI-компоненты.
*   `src/views/` — основные экраны приложения (текущий месяц, архив, настройки).
*   `src/utils/` — вспомогательные функции (экспорт, форматирование дат, обработка изображений).
*   `src/firebase.ts` — конфигурация и инициализация Firebase.

## Лицензия
Этот проект является частным инструментом для личного использования.
