## 3. Интерактивный Smoke-чеклист (пользовательские сценарии)

Чеклист всех пользовательских действий и механик приложения для проверки регрессий:

### 1. Навигация и общая оболочка (Shell)
- [ ] **Переключение табов:** Клик по табам «Кэшбек», «Архив», «Настройки» переключает экран с плавной fade-анимацией.
- [ ] **Скролл наверх:** При переключении таба или повторном клике на активный таб страница плавно скроллится в начало.
- [ ] **Мобильный Bottom Nav:**
  - На мобильных устройствах отображается компактный плавающий навбар.
  - При скролле вниз навбар скрывается / сворачивается; при скролле вверх — возвращается (`useScrollVisibility`).
  - Раскрытие навбара по тапу на свернутое состояние.
- [ ] **Переключение темы (Dark/Light):**
  - Клик на иконку Солнце/Луна в шапке (мобилка) или сайдбаре (десктоп).
  - Мгновенная смена фонов (`--surface-0/1/2`), текста и мета-тега `theme-color`.
  - Сохранение темы в `localStorage` и синхронизация в Firestore профиля.
- [ ] **Аутентификация Google:**
  - Клик «Войти» открывает Google Auth Popup.
  - Отображение аватара, имени и email после входа.
  - Клик «Выйти» вызывает модалку `ConfirmModal` («Вы уверены, что хотите выйти?»).
  - Пульсирующий индикатор синхронизации на аватаре при сохранении в облако.

### 2. Экран «Кэшбек» (Текущий период)
- [ ] **Выбор месяца:**
  - Переключение между текущим, предыдущим и следующим месяцем (доступен после 25-го числа).
- [ ] **Переключение вида:**
  - Тумблер «Таблица» / «Список».
- [ ] **Режим таблицы (`CashbackTable`):**
  - Отображение всех банков и категорий месяца.
  - Кнопка сортировки категорий: по возрастанию % и по убыванию % (состояние сохраняется в `localStorage`).
  - Быстрый экспорт из таблицы: клик по кнопкам PNG, Excel, PDF вызывает генерацию и скачивание.
- [ ] **Режим списка и Drag & Drop (`@dnd-kit`):**
  - Захват карточки банка за ручку/карточку и перемещение выше/ниже.
  - Сохранение нового порядка банков в локальный стейт и Firestore.
  - Клик на карандаш на карточке банка — открытие `BankForm` в режиме редактирования.
  - Клик на корзину на карточке банка — диалог подтверждения удаления банка из месяца.
- [ ] **Плавающая кнопка FAB (Добавление банка):**
  - Вертикальное перетаскивание FAB с прилипанием к краям (snapping).
  - Кнопка «глаз» для скрытия/показа FAB.
- [ ] **Форма добавления/редактирования банка (`BankForm`):**
  - Поиск банка по названию в поисковой строке.
  - Выбор банка из сетки предустановленных банков.
  - Добавление кастомного банка:
    - Ввод названия банка.
    - Загрузка логотипа с устройства.
    - Модалка обрезки (`react-easy-crop`): перемещение картинки, зум, сохранение кропа.
    - Удаление ранее созданного кастомного банка через модалку подтверждения.
  - Поиск категорий кэшбека через строку поиска.
  - Выбор/снятие категорий по клику на чипсы.
  - Создание новой кастомной категории кэшбека.
  - Ввод процента для выбранных категорий (числовые инпуты).
  - Кнопка «Сохранить» — запись в месяц и закрытие.
  - Кнопка «Отмена» — закрытие модалки без изменений.
- [ ] **Экспорт месяца из тулбара:** Кнопки скачивания PNG, Excel, PDF с тост-нотификациями об успехе/ошибке.

### 3. Экран «Архив»
- [ ] **Поиск по архиву:** Живой поиск по названию банка или категории фильтрует отображаемые месяцы.
- [ ] **Фильтры:**
  - Кнопка фильтра раскрывает панель фильтров.
  - Выпадающий список банков — выбор конкретного банка.
  - Выпадающий список категорий — выбор конкретной категории.
  - Кнопка сброса фильтра очищает выбор.
- [ ] **Аккордеон месяцев:**
  - Клик по карточке месяца раскрывает/сворачивает детальную информацию с плавной анимацией.
  - Внутри месяца: сетка логотипов банков с количеством категорий.
  - Кнопки экспорта внутри месяца: PNG, Excel, PDF.
  - Встроенная таблица `CashbackTable` внутри раскрытого месяца.
- [ ] **Удаление месяца:**
  - Клик по корзине у заголовка месяца открывает `ConfirmModal`.
  - Подтверждение удаляет весь месяц из архива и базы данных.

### 4. Экран «Настройки»
- [ ] **Справочник MCC-кодов (`MccDirectory`):**
  - Клик «Открыть справочник» открывает полноэкранный/bottom-sheet модал.
  - Поиск по 4-значному коду (например, `5411`), названию операции или группе.
  - Скролл списка с подгрузкой порций (инфинити/лимит).
  - Закрытие справочника.
- [ ] **Акцентный цвет (`--accent-color`):**
  - Клик по любому из 7 готовых кружков цветов (Emerald, Blue, Indigo, Purple, Rose, Orange, Amber) мгновенно меняет тему интерфейса.
  - Выбор кастомного цвета через Color Picker — срабатывает debounce, обновляются `--accent-color`, `--percent-bg`, `--percent-text`.
- [ ] **Форма логотипов:**
  - Выбор формы: Круг / Квадрат / Прямоугольник.
  - Мгновенно меняется геометрия всех логотипов банков во всех таблицах и карточках.
- [ ] **Цвет текста:**
  - Выбор пресета цвета текста или кастомный цвет через пипетку.
- [ ] **Экспорт и Бэкап:**
  - Кнопки быстрого экспорта текущего месяца: PNG, Excel, PDF.
  - Кнопка «JSON» (Экспорт) — формирует полный дамп данных (`allData`, `settings`, `customBanks`, `customCategories`) и скачивает `.json`.
  - Кнопка «Импорт» — выбор `.json` файла, валидация структуры, запись через `writeBatch` в Firestore, тост с результатом.
- [ ] **История версий (Admin):**
  - Отображается только для админа (`VITE_ADMIN_EMAIL`).
  - Клик открывает модалку `VersionHistory` с аккордеоном изменений по версиям.

### 5. PWA, Уведомления и Безотказность
- [ ] PWA Service Worker регистрируется без ошибок консоли.
- [ ] Оффлайн-работа: при отключении сети приложение открывается из кэша с сохраненными в `localStorage` данными.
- [ ] Очистка несуществующих/удаленных кастомных банков выполняется мягко при первом запуске.
- [ ] Тосты `sonner` корректно всплывают в правом нижнем углу (на десктопе) или снизу (на мобильном).
- [ ] `ErrorBoundary` перехватывает возможные сбои рендера и предлагает кнопку «Обновить».
