# Документация приложения Cashback Tracker Pro

## Обзор приложения
**Cashback Tracker Pro** — это полнофункциональное веб-приложение для мониторинга и управления категориями повышенного кэшбека в различных банках. Приложение позволяет пользователям консолидировать данные о своих банковских предложениях в одном месте, отслеживать историю по месяцам и настраивать интерфейс под свои предпочтения.

---

## 1. Основные разделы (Вкладки)

### 1.1. Кэшбек (Текущий месяц)
Центральный хаб для управления актуальными данными.
*   **Логика выбора месяца:** Приложение автоматически определяет текущий месяц. В период с 25-го числа текущего месяца по 5-е число следующего появляется переключатель, позволяющий заранее заполнить данные на будущий период или просмотреть предыдущий.
*   **Режимы отображения:**
    *   **Таблица:** Компактный вид всех банков с их категориями и процентами. Удобен для быстрого сравнения предложений.
    *   **Список банков:** Карточки банков с возможностью ручной сортировки через Drag-and-Drop.
*   **Управление банками:**
    *   Добавление банка через плавающую кнопку (FAB).
    *   Редактирование и удаление существующих записей.
*   **Плавающая кнопка (FAB):** 
    *   Адаптивное поведение: скрывается при прокрутке на мобильных устройствах для экономии места.
    *   Возможность перемещения по вертикали (снаппинг к 3 позициям: верх, центр, низ).

### 1.2. Архив
История всех сохраненных данных за предыдущие периоды.
*   **Группировка:** Данные сгруппированы по месяцам в обратном хронологическом порядке.
*   **Поиск и фильтрация:** Мощная система поиска по названию банка или категории, а также фильтры по конкретному банку или категории кэшбека.
*   **Экспорт:** Каждый месяц в архиве можно экспортировать отдельно в PDF, Excel или PNG.
*   **Удаление:** Возможность полной очистки истории за конкретный месяц.

### 1.3. Настройки
Раздел для персонализации и управления системными данными.
*   **Внешний вид:**
    *   **Акцентный цвет:** Выбор из предустановленной палитры или установка произвольного HEX-кода. Меняет цвет кнопок, иконок и выделений.
    *   **Цвет текста:** Настройка цвета основного шрифта приложения.
    *   **Форма логотипов:** Выбор между кругом, квадратом (squircle) или прямоугольником для всех логотипов банков.
    *   **Тема:** Переключение между светлым и темным режимами (синхронизируется с облаком).
*   **Инструменты:**
    *   **Справочник МСС:** Полнотекстовый поиск по базе МСС-кодов с описанием групп операций. Если код не найден, предлагается быстрый переход в Google.
    *   **История версий:** Список изменений и обновлений приложения (доступно для администратора).
*   **Данные и бэкап:**
    *   **Экспорт/Импорт JSON:** Полное резервное копирование всех данных приложения (настройки + история + кастомные банки).
    *   **Тестовые данные:** Возможность быстрого наполнения архива для ознакомления с функционалом.

## 2. Ключевой функционал и логика

### 2.1. Управление банками и категориями
*   **Предустановленные банки:** База популярных банков с официальными логотипами и цветами.
*   **Кастомные банки:** Возможность добавить свой банк, загрузить логотип, обрезать его встроенным инструментом (Cropper) и выбрать фирменный цвет.
*   **Категории:** Поддержка общих категорий и создание пользовательских. Каждой категории можно назначить процент кэшбека.

### 2.2. Синхронизация и безопасность
*   **Firebase Integration:** Авторизация через Google. При входе данные автоматически синхронизируются между устройствами в реальном времени.
*   **Local Storage:** Если пользователь не авторизован, данные сохраняются локально в браузере. При входе в аккаунт происходит миграция локальных данных в облако.
*   **Индикатор синхронизации:** Визуальное уведомление в профиле пользователя при совершении операций записи в БД.

### 2.3. Система экспорта
*   **PDF:** Генерирует чистый документ со списком категорий, оптимизированный для печати.
*   **Excel (XLSX):** Создает структурированную таблицу для дальнейшего финансового анализа.
*   **PNG (Изображение):** Создает красивую карточку таблицы, которой удобно поделиться в мессенджерах.
*   **Логика экспорта:** При экспорте из таблицы скрываются элементы управления (кнопки сортировки, удаления), оставляя только чистые данные.

### 2.4. Адаптивность (Responsive Design)
*   **Desktop (PC):** Полноценный боковой сайдбар, сетка настроек 2x2, расширенные таблицы.
*   **Tablet:** Оптимизированный макет, переходящий из двух колонок в одну в зависимости от ориентации.
*   **Mobile:** Компактная нижняя навигация, скрывающиеся элементы управления, полноэкранные модальные окна.

## 3. Технологический стек
*   **Frontend:** React + TypeScript.
*   **Styling:** Tailwind CSS (утилитарные классы).
*   **Animations:** Framer Motion (плавные переходы, Drag-and-Drop).
*   **Icons:** Lucide React.
*   **Backend/DB:** Firebase (Auth + Firestore).
*   **State Management:** React Hooks + LocalStorage Sync.
