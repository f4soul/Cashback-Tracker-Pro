# Задача: Рефакторинг UX/UI компонента `src/components/BankForm.tsx` (Гибрид концептов «Единый поток» + «Экспресс-ввод»)

Выполни рефакторинг формы добавления и редактирования банка (`BankForm.tsx`), опираясь на приложенный HTML-прототип и строго соблюдая все инварианты `AGENTS.md`.

## 1. Жесткие ограничения дизайн-системы и ESLint (`AGENTS.md`)
- **Никаких сырых радиусов Tailwind:** КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО использовать `rounded-lg`, `rounded-xl`, `rounded-2xl`, `rounded-3xl`. Используй только семантические токены проекта: `rounded-control` (для инпутов, кнопок, строк категорий, карточек в сетке), `rounded-card` / `rounded-modal` и `rounded-full` (для пилюль и круглых icon-buttons).
- **Никаких `transition-all`:** Используй исключительно точечные переходы: `transition-colors`, `transition-transform` или `transition-[background-color,border-color,box-shadow,transform]`.
- **Запрет инверсии поверхностей внутри модалки:** Модальное окно уже находится на слое `var(--surface-2)`. Внутри `BankForm.tsx` ЗАПРЕЩЕНО использовать `bg-[var(--surface-0)]` или `bg-[var(--surface-1)]` для вложенных контейнеров. Все интерактивные плашки, инпуты, строки выбранных категорий и элементы сетки должны строиться на `bg-[var(--fill)]` и `hover:bg-[var(--fill-hover)]` с границами `border-[var(--border-hairline)]`.
- **Zero Backdrop-Blur:** Sticky-футер формы должен иметь сплошной непрозрачный фон `bg-white dark:bg-[var(--surface-2)]` без `backdrop-blur-*`.
- **Типографика и склонения:** Используй `pluralize()` из `src/utils/format.ts` для счетчиков категорий (`1 категория`, `3 категории`, `5 категорий`). `uppercase tracking-widest` допустим только для микро-заголовков секций внутри модалки.

## 2. Архитектура интерфейса (Единый поток без вложенных скроллов)
Вся форма должна прокручиваться в едином потоке родительского `Modal` (без внутренних `max-h-* overflow-y-auto` контейнеров для категорий или банков).

### Блок 1: Выбор банка (Сворачиваемый CSS Grid аккордеон)
1. **Если банк уже выбран** (или форма открыта в режиме редактирования `initialData`):
   - Отображается компактная плашка выбранного банка (`rounded-control bg-[var(--fill)] border border-[var(--border-hairline)] p-2.5`) с компонентом `<BankLogo />`, названием банка и кнопкой «Сменить» справа.
   - Полный список выбора банков (поиск банка + сетка банков + кнопка создания кастомного банка) скрыт внутри аппаратного CSS Grid аккордеона: `grid transition-[grid-template-rows,opacity] duration-300 ease-out` (`grid-rows-[0fr] opacity-0 pointer-events-none` ↔ `grid-rows-[1fr] opacity-100 pointer-events-auto`) с внутренним `<div className="overflow-hidden min-h-0">`.
2. **Если банк еще не выбран** (добавление с нуля):
   - Аккордеон выбора банка по умолчанию раскрыт (`grid-rows-[1fr]`). Как только пользователь кликает на банк в сетке, банк выбирается, а аккордеон плавно сворачивается в компактную плашку, освобождая экран для категорий.
3. Сохрани существующую функциональность создания/редактирования/удаления кастомного банка и обрезки логотипа (`react-easy-crop`).

### Блок 2: Лоток выбранных категорий + Панель «Быстрый %»
1. **Лоток выбранных категорий:**
   - Заголовок секции со счетчиком выбранных категорий справа (`bg-[var(--percent-bg)] text-[var(--percent-text)] rounded-full`).
   - Каждая выбранная категория рендерится отдельной компактной строкой (`rounded-control bg-[var(--fill)] border`). Никакого Drag-and-Drop внутри этого списка не нужно.
   - **Механика активной категории (`activeCategoryName: string | null`):**
     - При добавлении новой категории из сетки ниже или при клике на строку в лотке эта категория становится активной (`activeCategoryName`), получая акцентную подсветку рамки (`border-[var(--accent-color)]/60 ring-1 ring-[var(--accent-color)]/25`), но **без** автоматического вызова `.focus()` на инпуте (чтобы на мобильных устройствах не выпрыгивала экранная клавиатура и не перекрывала список).
   - Справа в строке: компактный инпут процента (`inputMode="decimal"`, класс `no-spinner`, поддержка как чисел `"5"`, `"2.5"`, так и строк вроде `"до 10%"`, процент необязателен) и кнопка удаления категории из выбранных (`×`).
2. **Панель «Быстрый %»:**
   - Сразу под лотком выбранных категорий (если выбрана хотя бы одна категория) расположи компактную строку быстрых пресетов: `['1', '3', '5', '7', '10', '15']`.
   - Тап по пилюле пресета мгновенно записывает это значение в `percent` текущей активной категории (`activeCategoryName`, либо последней добавленной, если активная не задана). Если у активной категории процент совпадает с чипом, чип подсвечивается токенами `bg-[var(--percent-bg)] text-[var(--percent-text)] border-[var(--accent-color)]/40`.

### Блок 3: Поиск / Создание категории и 2-колоночная сетка
1. **Умное поле поиска и создания:**
   - Одно поле ввода `rounded-control bg-[var(--fill)]` с иконкой лупы слева и встроенной кнопкой «+ Создать» (`rounded-control bg-[var(--accent-color)] text-white`) справа внутри инпута.
   - По мере ввода текст фильтрует сетку категорий ниже. По клику на «Создать» (или `Enter`) создается кастомная категория (если такой еще нет) и сразу добавляется в выбранные, становясь `activeCategoryName`.
2. **Сетка всех категорий (`grid grid-cols-2 gap-1.5`):**
   - Карточки фиксированной минимальной высоты (`min-h-[40px] rounded-control`).
   - **Выбранная категория в сетке:** заливается `bg-[var(--accent-color)] text-white`, справа отображается бейдж с текущим процентом (`bg-white/20`). Повторный клик снимает выбор.
   - **Невыбранная категория:** `bg-[var(--fill)] hover:bg-[var(--fill-hover)] border border-[var(--border-hairline)]`, справа иконка `Plus`. Для пользовательских категорий (`customCategories`) справа у края карточки сохраняется аккуратная кнопка удаления кастомной категории из справочника (`×`).

### Блок 4: Sticky-футер с живой сводкой
- Закреплен внизу через `sticky -bottom-3 sm:-bottom-4 z-20 bg-white dark:bg-[var(--surface-2)] pt-3 pb-[max(0.75rem,env(safe-area-inset-bottom))] border-t border-[var(--border-hairline)]`.
- Вместо двух кнопок («Отмена» / «Сохранить») сделай одну полноширинную акцентную кнопку сохранения (`w-full h-11 rounded-control bg-[var(--accent-color)] text-white font-bold`), внутри которой справа в полупрозрачном бейдже (`bg-white/20`) выводится живая сводка: количество выбранных категорий через `pluralize()` и максимальный числовой процент среди них (например: `3 категории · до 7%`).
